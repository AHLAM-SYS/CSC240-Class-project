Project Proposal: Daycare Management System

Application Description
My project is a database for a small daycare center. It will help staff organize information about children, parents, teachers, classes, and attendance.
Staff can find parent contact information and keep track of children’s daily attendance.

Entities
I plan to include these entities, which will become tables:

Children: Child ID, name, and date of birth.
Parents: Parent ID, name, phone number, and email.
Teachers: Teacher ID, name, and phone number.
Classes: Class ID, class name, and age group.
Attendance: Attendance ID, child ID, date, and attendance status.
Children will be linked to their parents and assigned to classes. Teachers will also be assigned to classes.

Business Processes
The database will support these activities:

Register a new child and link the child to a parent.
Add or update parent contact information.
Assign a child to a class.
Assign a teacher to a class.
Record whether a child is present or absent each day.
View the list of children in each class.
